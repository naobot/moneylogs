# FreshNotice

A row that says news is waiting for you, and opens it: the drawer's alerts, a friend request to answer, a month review card.

- 1px frame with the 4px `border-fresh` left edge, 44px tall. As a link row it leads with the bouncing `warning` icon and ends with `›`.
- As a card (month review, incoming friend request) it holds a short line and its answers: the main one 2px, the other 1px.
- Fresh means waiting for you. Once answered, it goes.

**Consumer provides:** the line, and either a target or the answers.
