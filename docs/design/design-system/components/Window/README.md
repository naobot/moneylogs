# Window

The page-level frame: `border-rule` on `paper`, `window-pad` (30px) inside.

**(2026-11)** Desktop and medium screens only. On phones a page has no Window: the striped TitleBar is its header and content runs edge to edge inside 12px (the frame and padding were costing ~80px of a 390px screen).
**Use** for login, create, settings and summary blocks on wide screens. Pair with `Tabs` directly above it for filing-folder sections.
**Don't** nest a Window in a Window; inside one, use section labels or disclosures.
