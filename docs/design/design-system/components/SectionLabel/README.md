# SectionLabel

**(2026-11)** How sections are split on the ground instead of boxes or inverted strips: a bold 13px lowercase label on a 1px solid rule, with an optional muted count or a 44px caps text action at the right ("edit", "manage", "see all 9").

The **day header** is a section label carrying the day's total (`wed 25 nov ·· ¥ 6,900`). **Today's** day header is the one exception: a 30px black bar, `today · thu 26 nov`, once per list (see the inversion budget).
