# Disclosure

**(2026-11)** A secondary block that starts folded: the category breakdown, a month review, scheduled payments, the knick-knack drawer.

A 40–44px text button, `[+] title` on the left and a muted count or note on the right, no frame. Opened, it reads `[-] title`, and its content hangs off a 1px dotted rule on the left. When the opened content is itself something to act on (the month review), it becomes a framed box with a black header bar instead. Remember each one's open state per user, like display prefs. On wide screens a disclosure may start open (the breakdown in the aside).

Supersedes `Drawer` for in-page blocks; settings sections are now a list of pages (see the /me audit screens).
