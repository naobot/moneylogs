# ChoiceCard

A large framed option in the create-log wizard; the whole card is the button.

**Consumer provides:** a bold lowercase title, one sentence of explanation, selected state.
**Use** for a decision with 2–4 big, different outcomes (log group vs financial log). Selected inverts; hover inverts only behind `@media (hover: hover)`.
**(2026-11)** Frame is `border-hairline` (card tier), not 2px. For answers that are a sentence each (the budget wizard's saving styles) use radio rows (see Check) instead of cards.
Hand-written from `.CreateLogWizard__choice`.
