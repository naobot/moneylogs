# Slides

A short explainer in steps, such as "what's a sublog?": a tall bottom sheet on phones, a centred box on wide screens.

- Black header (the overlay rule) with the title and `×`.
- Each slide: a lowercase heading, an optional picture made of the app's own pieces, one paragraph, and an example in a 1px `sheet` card that starts "For example:".
- Footer: square dots for the position (the current one filled), `skip` as a `TextButton`, back (1px) and next (2px). The last slide swaps next for its action ("start a sublog").

**Consumer provides:** the slides (heading, text, optional art and example), the closing action.
