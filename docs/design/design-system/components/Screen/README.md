# Screen

A reference screen showing the whole system together: nav, dashboard cards, the ledger, a striped-title modal with a danger zone, and a settings form.

Use it as the check for any change to tokens or type: if something new looks out of place here, it is out of place in the app. Everything is set in Hack; button labels are caps-lock, and nav log titles keep their own case because they are user content. Toggle Night shift to see the swapped inks; in the app the sun/moon button left of sign-out does the same.
