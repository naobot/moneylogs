# UpdateBanner

A notice that a newer build is out, with one button to load it.

**(2026-11)** Fresh news, so it takes the 4px `border-fresh` left edge on a 1px frame. Phones show it under the nav, inside the page margin; wide screens put it under the nav across the content width. One action, Refresh (2px).

**Consumer provides:** nothing: driven by `useAppVersionRefresh`.
