# Drawer

A collapsible section on native `<details>`: a ruled summary bar that inverts while open, with a text-mode `[+]` / `[-]` marker.

**(2026-11) Being retired.** In-page folding uses Disclosure (no frame, no inversion: an open drawer was a structural black bar). The settings page is now a list of section pages on phones and nav + pane on desktop. Not to be confused with the knick-knack drawer, which is a home-page section (see KnickKnack).
