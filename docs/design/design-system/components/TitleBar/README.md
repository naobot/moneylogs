# TitleBar

**(2026-11)** Every page's header: the chrome of early desktop windows.

A `border-rule` frame, 44px on phones and 48px on desktop, filled with 1px ink stripes with 3px gaps, inset from the frame (6px top and bottom, 4px at the sides). The page title (16–18px bold, user text keeps its case) sits on a `paper` label at the left; actions sit on a second paper label at the right — 40px icon buttons on phones and medium screens, icon + word on wide ones. On a log, the view toggle (Segmented, primary) sits flush underneath, sharing the bottom line.

Modals don't use it: an overlay's header is the black bar. Replaces the inverted `Group__header` strip.
