# Comment

A speech-bubble comment beside its post: hairline frame with a square tail pointing left.

`--highlight` (the viewer's own or the newest) inverts. Below `bp-md` comments become a horizontal bottom sheet and drop the tail.
Corners use `radius-bubble` (10px), shared with the other speech bubbles (see Bubble) — a sanctioned exception, because it imitates a speech balloon. The tail stays a hard-edged triangle.
