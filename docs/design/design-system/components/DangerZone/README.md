# DangerZone

The last section of a management modal or sheet.

**(2026-11)** Danger is said with weight and words, not a second black block: a `border-heavy` rule above the section, a heading prefixed with `!` (`! delete this log`), copy that names exactly what is lost, and a destructive button in a `border-heavy` frame ending in `…` when a confirmation follows. Irreversible deletes still require typing the log's name into a text field.
