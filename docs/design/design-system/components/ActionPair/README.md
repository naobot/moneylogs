# ActionPair

Two light, repeatable actions joined into one smaller control, so they don't compete with the screen's main button: poke · cheer.

- 1px frame split by its own line, words in body case (not caps), 44px tall on phones, 36px on wide.
- A half that opens a menu (cheer ▾) inverts while open. A half that counts (poke) shows its count: "poked ×3".
- Sits under the main action (send a gift) on profiles, and at the top of the home friends menu.

**Consumer provides:** the two actions and their labels; see Action weight in the README.
