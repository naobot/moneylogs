Pixel-art icons, single ink `#242424` (`ink`) on transparent, shown as `<img>` from `public/icons/`. File names credit the artist (Noun Project): `nakals-`, `reandra-khansa-`, `kanyayee-`, `bluetip-`; ten are drawn in-house with the `moneylogs-` prefix (bell, caret, eye, folder, gear, gift, smiley, social, star, wallet). Because an `<img>` can't inherit colour, add `.Icon--inverse` (invert filter) on `inverse-surface` and in Night shift. New icons: pixel grid, square corners, single ink, prefix `moneylogs-`. Where each one is used: see Iconography in the README.
